# Katere funkcionalnosti so bile uspešno implementirane za MVP?
Implementirane so bile vse zahteve MVP:
- Dostop glede na vlogo
- Evidenca lastnih vozil
- Objava in rezervacija termina
- Prvezmen in potek pregleda
- Izpolnjevanje kontrolnega seznama
- Evidentiranje napak po postavkah
- Izračun izida in zgodovina vozila
